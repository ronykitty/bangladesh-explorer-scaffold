# বাংলাদেশ এক্সপ্লোরার

React + TypeScript + Vite + Supabase দিয়ে বানানো Progressive Web App — বাংলাদেশের প্রতিটি জেলা-উপজেলার নদী, ঘাট, হেরিটেজ, খাবার, মিষ্টি ট্র্যাক করার জন্য।

## এই মডিউলে যা আছে (Scaffold)

- Vite + React 19 + TypeScript প্রজেক্ট সেটআপ
- Tailwind CSS v4 (Vite প্লাগইন দিয়ে, postcss config লাগে না)
- vite-plugin-pwa দিয়ে PWA কনফিগারেশন (manifest, service worker, offline caching)
- Supabase ক্লায়েন্ট সংযুক্ত (`src/lib/supabase.ts`)
- React Router দিয়ে ১৭টা রুট (ড্যাশবোর্ড, প্লেস, ক্যাটাগরি পেজ, গ্যালারি, উইশলিস্ট, প্ল্যানার, জার্নাল, সেটিংস)
- React Query provider সেটআপ
- লাইট/ডার্ক/সিস্টেম থিম সিস্টেম, localStorage-এ সেভ হয়
- রেসপন্সিভ লেআউট — ডেস্কটপে ফিক্সড সাইডবার, মোবাইলে স্লাইড-ইন ড্রয়ার (Framer Motion দিয়ে অ্যানিমেটেড)
- গ্লাসমরফিজম স্টাইল (topbar, card গুলোতে)

## চালানোর নিয়ম

```bash
npm install
npm run dev
```

তারপর ব্রাউজারে http://localhost:5173 খোলো।

## Environment Variables

`.env.local` ফাইলে তোমার Supabase প্রজেক্টের তথ্য বসানো আছে:

```
VITE_SUPABASE_URL=https://xaummlewqjletagnuxhu.supabase.co
VITE_SUPABASE_PUBLISHABLE_KEY=sb_publishable_...
```

`.env.example` ফাইলে টেমপ্লেট আছে — অন্য কোথাও ডিপ্লয় করলে ওই ভ্যারিয়েবল দুটো সেট করে দিও।

## Authentication (নতুন — এই মডিউলে যোগ হয়েছে)

- ইমেইল/পাসওয়ার্ড দিয়ে সাইনআপ, লগইন, লগআউট
- পাসওয়ার্ড ভুলে গেলে রিসেট (ইমেইলে লিংক পাঠানো হয়)
- সাইনআপে ইমেইল কনফার্মেশন হ্যান্ডলিং
- সব `/`, `/places`, `/category/*` ইত্যাদি রুট এখন প্রোটেক্টেড — লগইন ছাড়া ঢোকা যাবে না, স্বয়ংক্রিয়ভাবে `/login` এ পাঠিয়ে দেবে
- লগইন করা থাকলে `/login`, `/signup` এ গেলে সরাসরি ড্যাশবোর্ডে রিডাইরেক্ট হবে
- সাইডবারের নিচে ইউজারের ইমেইল ও লগআউট বাটন

⚠️ **Supabase Dashboard-এ একটা সেটিং করতে হবে:** Authentication → URL Configuration এ গিয়ে **Site URL** এবং **Redirect URLs**-এ তোমার dev/production URL যোগ করো (যেমন `http://localhost:5173`, আর পরে ডিপ্লয় করলে সেই ডোমেইনও), নাহলে পাসওয়ার্ড-রিসেট ও ইমেইল-কনফার্মেশন লিংক কাজ করবে না।

## Places CRUD (নতুন — এই মডিউলে যোগ হয়েছে)

- নতুন এন্ট্রি যোগ করার ফর্ম — বিভাগ→জেলা (cascading select), উপজেলা, ইউনিয়ন/গ্রাম, ২০টা ক্যাটাগরি, ৪-স্টেজ স্ট্যাটাস (যেতে চাই → পরিকল্পিত → ঘুরে এসেছি → আবার গিয়েছি), ছবির লিংক, Google Maps লিংক, নিজের রেটিং, পরিকল্পিত তারিখ, বর্ণনা
- এডিট ও ডিলিট (কনফার্মেশনসহ)
- প্রতিটা এন্ট্রিতে একাধিক ভিজিট যোগ/মোছার ব্যবস্থা (তারিখ + নোট)
- সব পেজ এখন আসল Supabase ডেটা দেখায়:
  - **ড্যাশবোর্ড** — লাইভ স্ট্যাট, ক্যাটাগরি ব্রেকডাউন, বছর/মাস ভিজিট রিপোর্ট
  - **সব প্লেস** — সব এন্ট্রি, ফিল্টার+সার্চসহ
  - **ক্যাটাগরি পেজগুলো** — শুধু সেই ক্যাটাগরির এন্ট্রি
  - **উইশলিস্ট** — শুধু "যেতে চাই" এন্ট্রি
  - **গ্যালারি** — ছবি-সহ এন্ট্রি গ্রিড আকারে
  - **প্ল্যানার** — পরিকল্পিত মাস অনুযায়ী গ্রুপ করা
  - **জার্নাল** — সব ভিজিট সময়ানুক্রমে
- React Query দিয়ে ক্যাশিং ও অটো-রিফ্রেশ (একটা মিউটেশনের পর পুরো লিস্ট আবার লোড হয়)

- Export/import, sharing, public profile

## Database Schema (নতুন — এই মডিউলে যোগ হয়েছে)

`supabase/migrations/` ফোল্ডারে ৩টা মাইগ্রেশন ফাইল আছে:

1. `0001_core_schema.sql` — টেবল (divisions, districts, categories, places, visits), enum, trigger, RLS policy
2. `0002_seed_divisions_districts.sql` — ৮টা বিভাগ + ৬৪টা জেলা (যাচাই করা)
3. `0003_seed_categories.sql` — ২০টা ক্যাটাগরি

**একবারে সব চালাতে চাইলে** `RUN_ALL_IN_SQL_EDITOR.sql` ফাইলটা পুরো কপি করে Supabase Dashboard → SQL Editor-এ পেস্ট করে Run চাপো। তিনটাই একসাথে আছে ওই ফাইলে।

⚠️ **গুরুত্বপূর্ণ:** `places` ও `visits` টেবিলের RLS পলিসি `auth.uid()` এর উপর নির্ভর করে — মানে লগইন ছাড়া কেউ কোনো প্লেস যোগ/দেখতে পারবে না। Authentication মডিউল তৈরি না হওয়া পর্যন্ত অ্যাপ থেকে সরাসরি প্লেস যোগ করা যাবে না, কিন্তু SQL Editor থেকে টেস্ট ডেটা ইনসার্ট করে দেখা যাবে।
